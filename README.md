
# Projeto: Integração MySQL com Python

Este projeto demonstra como usar Python para executar operações básicas com MySQL, utilizando a biblioteca `mysql-connector-python`. O código foi desenvolvido no Google Colab, com base nos tutoriais da W3Schools.

## Tecnologias
- Python (Google Colab)
- MySQL
- mysql-connector-python

## Funcionalidades
- MySQL Get Started
- mysql-connector-python
- MySQL Create Database
- MySQL Create Table
- MySQL Insert
- MySQL Select
- MySQL Where
- MySQL Order By
- MySQL Update
- MySQL Delete
- MySQL Limit
- MySQL Join

## Observação
Todas as práticas seguem os exemplos da W3Schools.
